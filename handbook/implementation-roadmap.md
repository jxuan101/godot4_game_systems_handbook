# Suggested Implementation Roadmap

1. Foundation: input, movement, health, scene management, save/load.
2. Gameplay loop: combat, enemy AI, pickups, inventory, HUD.
3. Content systems: items, equipment, abilities, quests, progression.
4. World systems: procedural rooms, caves, loot, hazards, chunk loading.
5. Polish: audio, menus, dialogue, notifications, effects, accessibility.
6. Advanced: multiplayer, replay, dynamic difficulty, time manipulation.

Do not implement all 80 systems in one game. Treat the catalog as a menu of reusable patterns.
