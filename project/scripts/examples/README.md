# Working Godot 4 Examples

This directory contains **80 system-specific GDScript examples**, one for each handbook system. These are concrete implementations of each system's core behavior, not empty lifecycle scaffolds. Attach each script to the node type declared at the top of the file. See the matching handbook page for purpose, architecture, integration notes, and test checklist.
